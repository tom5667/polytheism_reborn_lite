# Polytheism Reborn — Changelog

Update for Crusader Kings III 1.20.1. Existing saves keep working.

## New

## Fixes & historical accuracy
- **Norse and German holy sites restored.** CK3 1.20.1 removed the holy sites Lejre and Zeeland, so the Norse and the German faith each lost one. They are back in the same place (Lejre on Sjælland, Zeeland at the Scheldt mouth) with the same bonuses.
- **Faith window updated for CK3 1.20.1.** The window now includes all of Paradox's 1.20.1 changes; the Cults tab works as before.
- **Religion family names follow the game again.** Only "Pagan" is renamed to "Polytheistic"; the other families keep their own names, such as the new "Dharmic".
